Homework Part I: fundamentals

In this order: (1) Code Lab 1 on your own laptop, (2) 50 steps of your current FreeCodeCamp certification.

1 · Both runtimes work

  1. In a terminal: 
    node --version
python3 --version
    Windows: python --version.

    If this breaks: "command not found" = not installed. Use the Docker commands in Code Lab 1, or the Playground.

2 · Code Lab 1

  1. Every section of Code Lab 1 in your fundamentals folder. Type it, run it, and check the output matches.
  2. Then change something on purpose (a value, a name, true → True) and predict the output before you run it.

Homework Part II: algorithm assignments

In this order, top to bottom (each is a little harder): (1) Factorial (JS), (2) Roman Numerals (JS), (3) 99 Bottles (Python), (4) Factorial (Python), (5) Fibonacci (Python). Then 50 steps of your current FreeCodeCamp certification.

3 · Get each assignment

  1. Open the assignment on GitHub and click Fork (top right) → Create fork. Now there's a copy under your account.
  2. Clone your fork and open it (Factorial as the example): 
    git clone https://github.com/YOUR-USERNAME/algo-factorial.git
cd algo-factorial
code .
    VS Code may offer to Reopen in Container. You can skip it: plain node and python3 are enough.
  3. Read the README first. Write your plan as comments (pseudocode) before any code.

4 · Solve it, then run the spec

  1. Write your code in the function that's already there. The spec file calls it and prints true / True for each check that passes:
    AssignmentYour codeCheck it with
    Factorial (JS)factorial.jsnode factorialSpec.js
    Roman Numerals (JS)romanNumerals.jsnode romanNumeralsSpec.js
    99 Bottles (Python)bottles.pypython3 bottles.py, compare with the song in the README
    Factorial (Python)factorial.pypython3 factorial_spec.py
    Fibonacci (Python)fibonacci.pypython3 fibonacci_spec.py
  2. Done = every line prints true / True.

    If you see false: make sure your function returns the answer (Lecture 2: printing is not returning). None / undefined = no return.

5 · Commit and push

  1. From inside the assignment folder: 
    git add -A
git commit -m "Solve factorial"
git push
    Or ask Claude (in the assignment folder): 
    Run git status and show me the list of files. Then suggest a commit message for my solution and wait for my approval. After I approve, commit and push to my fork.
    Claude asks before each git command. Read the file list before you say yes.

    If this breaks: "Permission denied" or 403 on push = you cloned the Code Platoon repo, not your fork. git remote set-url origin https://github.com/YOUR-USERNAME/algo-factorial.git, then push again.
