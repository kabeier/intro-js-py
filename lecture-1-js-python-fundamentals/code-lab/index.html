Before you start

  1. Make the folders and open them in VS Code: js/ for every JavaScript file, python/ for every Python file. 
    mkdir fundamentals
cd fundamentals
mkdir js python
code .
    code: command not found? Open VS Code, then File → Open Folder and pick fundamentals.
  2. Docker is running (Mac/Windows: open Docker Desktop first). In VS Code's terminal (Ctrl+`): 
    docker --version
docker run --rm hello-world
docker pull node:18-alpine
docker pull python:3.11-slim
    You don't need Node or Python installed: Docker brings them.

The two Dockerfiles

The lesson's Dockerfiles, with one change: COPY . . copies every file in the folder, so one image can run any of today's files. Each one lives in its own folder and is named just Dockerfile, so docker build finds it by itself.

fundamentals/
├── js/
│   ├── Dockerfile
│   └── example.js   (and every .js file today)
└── python/
    ├── Dockerfile
    └── example.py   (and every .py file today)

js/Dockerfile

FROM node:18-alpine
WORKDIR /app
COPY . .
CMD ["node", "example.js"]

python/Dockerfile

FROM python:3.11-slim
WORKDIR /app
COPY . .
CMD ["python3", "example.py"]

Two terminals (VS Code: the + or split button in the terminal panel): one for each folder. They stay there all lecture.

cd js
cd python

Every time you run a file: build, then run. The words after the image name replace the CMD, so the same image runs any file. --init lets Ctrl+C stop a program (without it, Ctrl+C can't stop Node inside a container).

docker build -t js-fundamentals .
docker run --rm --init js-fundamentals node example.js

Edited a file? Build again. COPY is a snapshot taken at build time: without a rebuild the image still has your old code (Monday's lesson). Mac/Linux: docker build … && docker run … does both in one line, and ↑ repeats it. Or try a snippet in the Playground.

5 · Can it change?

New files: js/mutable.js and python/mutable.py. Type each block yourself (copy only if you fall behind), save, then build and run: the .js file in your js/ terminal, the .py file in your python/ terminal.

js/mutable.js · part 1

// a list is mutable: it changes in place
let colors = ["red", "green"];

console.log(colors);

js/mutable.js · part 2 (add below)

// a string is immutable: you get a NEW string
let name = "alex";

console.log(name, loud);

js/mutable.js · part 3 (add below)

// the bug: two labels, one list

console.log(colors);

When something breaks

You seeIt meansFix
Cannot connect to the Docker daemonDocker Desktop isn't runningOpen Docker Desktop and wait, then try again
The old output, after you edited the fileYou didn't rebuild: the image has the old copydocker build … again, then run
Error: Cannot find module '/app/variables.js' / can't open file '/app/variables.py'The file is new and the image is old (or the name is misspelled)Save, rebuild, run
pull access denied for js-fundamentalsYou ran before building (or the tag is misspelled)docker build -t js-fundamentals . (in js/)
failed to read dockerfile: open DockerfileThe terminal isn't in js/ or python/, or the file isn't named exactly Dockerfilepwd, then cd js (or cd python)
Cannot find module '/app/…' even after a rebuildThe file is in the wrong folder (a .js file in python/, or in fundamentals/ itself)Move it into js/, rebuild
ReferenceError: True is not definedPython's True in a JS fileJS is lowercase: true, false, null
NameError: name 'true' is not definedJS's true in a Python filePython is capitalized: True, False, None
SyntaxError: Identifier 'userName' has already been declaredlet twice for the same nameOnly the first time gets let
ReferenceError: print is not defined / NameError: name 'console' is not definedMixed the two languages' printJS: console.log() · Python: print()
