Code Lab 1: variables and data types

Type along with Lecture 1. Each section is one pair of files: a .js and a .py that do the same thing. Every block has a Copy button and shows what you should see when you run it. Type it yourself first: your fingers learn the syntax.

In classSections 1–5 follow the slides. Something broke?Jump to the table at the bottom.

Before you start

  1. Make a folder and open it in VS Code: 
    mkdir fundamentals
cd fundamentals
code .
    code: command not found? Open VS Code, then File → Open Folder and pick fundamentals.
  2. Open VS Code's terminal: Terminal → New Terminal (or Ctrl+`). Check both runtimes: 
    node --version
python3 --version
    v22.x.x           ← any v18 or newer is fine
Python 3.12.x     ← any 3.10 or newer is fine
    Windows: use python instead of python3 everywhere on this page.
  3. New file: hover the folder name in the Explorer and click the New File icon. Save (Ctrl+S / Cmd+S) before every run.

No Node or Python? Use Docker

Run your file inside a container that has the runtime. -v lends the container your folder (the bind mount from the Docker lecture), -w /app starts there.

Mac · Linux · WSL

docker run --rm -v "$PWD":/app -w /app node:18-alpine node example.js
docker run --rm -v "$PWD":/app -w /app python:3.11-slim python3 example.py

PowerShell

docker run --rm -v "${PWD}:/app" -w /app node:18-alpine node example.js
docker run --rm -v "${PWD}:/app" -w /app python:3.11-slim python3 example.py

Git Bash: put MSYS_NO_PATHCONV=1 in front. Swap example.js for each file name on this page.

Or try any snippet in the Playground: JavaScript and Python running right in the browser.

5 · Can it change?

New files: mutable.js and mutable.py. Type each block yourself (copy only if you fall behind), save, run.

mutable.js · part 1

// a list is mutable: it changes in place
let colors = ["red", "green"];
colors.push("blue");
console.log(colors);

mutable.js · part 2 (add below)

// a string is immutable: you get a NEW string
let name = "alex";
let loud = name.toUpperCase();
console.log(name, loud);

mutable.js · part 3 (add below)

// the bug: two labels, one list
let copy = colors;
copy.push("pink");
console.log(colors);
node mutable.js
[ 'red', 'green', 'blue' ]
alex ALEX
[ 'red', 'green', 'blue', 'pink' ]

mutable.py · part 1

# a list is mutable: it changes in place
colors = ["red", "green"]
colors.append("blue")
print(colors)

mutable.py · part 2 (add below)

# a string is immutable: you get a NEW string
name = "alex"
loud = name.upper()
print(name, loud)

mutable.py · part 3 (add below)

# the bug: two labels, one list

copy.append("pink")
print(colors)

alex ALEX

Bonus · The same files, in Docker

The two Dockerfiles from the lesson. Make both in your fundamentals folder (two Dockerfiles in one folder need two names; -f picks one).

Dockerfile.node

FROM node:18-alpine
WORKDIR /app
COPY example.js .
CMD ["node", "example.js"]

Dockerfile.python

FROM python:3.11-slim
WORKDIR /app
COPY example.py .
CMD ["python3", "example.py"]
docker build -t hello-js -f Dockerfile.node .
docker run --rm hello-js
docker build -t hello-py -f Dockerfile.python .
docker run --rm hello-py

Hello from Python
