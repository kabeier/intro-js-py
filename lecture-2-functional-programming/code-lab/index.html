Break it on purpose · an infinite loop

In more-loops.js, delete the line count++;, save, build, run. count stays 0 forever, so 0 prints forever.

Stop it: click in the terminal and press Ctrl+C (Mac too: Control, not Command). It works because of --init: without it, Node ignores Ctrl+C inside a container (then: docker ps and docker stop <name> in another terminal). Put the line back, rebuild. Same in Python with count += 1.
