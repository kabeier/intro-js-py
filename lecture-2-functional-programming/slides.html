Loop a list: by value, by index, or both loops.js · loops.py

** CODE ALONG, about 5 minutes. ** Students: loops.js, loops.py. Run after each pair.

TYPE THIS, in order

loops.js · part 1

let colors = ["red", "green", "blue"];

// by value: for...of
for (let color of colors) {
  console.log(color);
}

loops.py · part 1

colors = ["red", "green", "blue"]

# by value: for...in
for color in colors:
    print(color)

loops.js · part 2 (add below, after a blank line)

// by index
for (let i = 0; i < colors.length; i++) {
  console.log(i, colors[i]);
}

loops.py · part 2 (add below, after a blank line)

# by index
for idx in range(len(colors)):
    print(idx, colors[idx])

loops.js · part 3 (add below, after a blank line)

// both
for (const [idx, color] of colors.entries()) {
  console.log(idx, color);
}

loops.py · part 3 (add below, after a blank line)

# both
for idx, color in enumerate(colors):
    print(idx, color)

  • By value is the most common. JS is for of; Python is for in.
  • By index, JS: let i = 0 start · i < colors.length keep going while true · i++ add 1 after each pass.
  • Python: range(3) gives 0, 1, 2 (up to, not including, 3).
  • Both: entries() / enumerate() hand back [index, value] pairs; we unpack each pair into two variables.

Arrow, lambda, filter, sort, map functional.js · functional.py

** CODE ALONG, about 4 minutes. ** Students: functional.js, functional.py.

TYPE THIS, in order

functional.js · part 1

const multiply = (a, b) => a * b;
console.log(multiply(3, 4));

functional.py · part 1

multiply = lambda a, b: a * b
print(multiply(3, 4))

functional.js · part 2 (add below, after a blank line)

let nums = [3, 1, 4, 2];
let evens = nums.filter(n => n % 2 === 0);
let doubled = nums.map(n => n * 2);
console.log(evens, doubled, nums);

functional.py · part 2 (add below, after a blank line)

nums = [3, 1, 4, 2]
evens = list(filter(lambda n: n % 2 == 0, nums))
doubled = [n * 2 for n in nums]
print(evens, doubled, nums)

functional.js · part 3 (add below, after a blank line)

nums.sort((a, b) => a - b);
console.log(nums);

functional.py · part 3 (add below, after a blank line)

sorted_nums = sorted(nums)
print(sorted_nums, nums)

  • Arrow (JS) / lambda (Python): a one-line function. Used inside filter, map and sort.
  • n % 2 === 0: remainder 0 means even.
  • filter and map / list comprehension: new lists. nums is untouched.
  • Step 5: JS .sort() changes nums itself. Python sorted() makes a new list; nums stays [3, 1, 4, 2].

New list, or changes yours?

JS .sort() alone sorts as text: [10, 9, 1] → [1, 10, 9]
Always add (a, b) => a - b

"Constructive builds a new list. Destructive changes the one you have." Same idea as mutable from Lecture 1.

  • Read it row by row: same task, JS on the left, Python on the right. Green rows leave nums alone; the red row changes it.
  • What we typed in slide 12: JS nums.sort(…) = the red row. Python sorted(nums) = the green sorted-copy row. That's why the two terminals printed different nums.
  • [...nums] = "a copy of nums" (spread). Sort the copy, and nums is safe.
  • Trap: Python nums.sort() returns None. x = nums.sort() gives you None.

The yellow bar is the activity's bonus card. Why (a, b) => a - b: without it, JS compares the numbers as text.
