Loop a list: by value, by index, or both loops.js · loops.py

** CODE ALONG, about 5 minutes. ** Students: loops.js, loops.py. Run after each pair.

  • By value is the most common. JS is for of; Python is for in.
  • By index, JS: let i = 0 start · i < colors.length keep going while true · i++ add 1 after each pass.
  • Python: range(3) gives 0, 1, 2 (up to, not including, 3).
  • Both: entries() / enumerate() hand back [index, value] pairs; we unpack each pair into two variables.

Write it once, call it often functions.js · functions.py

** CODE ALONG, about 5 minutes. ** Students: functions.js, functions.py.

  • Declare (JS function) / define (Python def). Nothing happens until you call it.
  • DRY: Don't Repeat Yourself. Two calls, two prints, one definition.
  • Steps 3–4, then R: before running, ask "what is result?" The greeting prints, but result is undefined / None. Text in the terminal ≠ a returned value.
  • Steps 5–6 change one line (it lights up yellow): console.log → return. R again: now result holds the greeting, and greet("Alice") prints nothing. Returning doesn't print.

Arrow, lambda, filter, sort, map functional.js · functional.py

** CODE ALONG, about 4 minutes. ** Students: functional.js, functional.py.

  • Arrow (JS) / lambda (Python): a one-line function. Used inside filter, map and sort.
  • n % 2 === 0: remainder 0 means even.
  • filter and map / list comprehension: new lists. nums is untouched.
  • Step 5: JS .sort() changes nums itself. Python sorted() makes a new list; nums stays [3, 1, 4, 2].
